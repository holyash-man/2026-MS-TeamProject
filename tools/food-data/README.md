# 음식 영양 데이터 (식약처 100개)

앱의 음식 100개와 영양성분은 아래 공공 데이터에서 뽑아 `app/src/main/assets/foods.json` 으로 만든다.

- **출처**: 식품의약품안전처, 「전국통합식품영양성분정보(음식)표준데이터」
- **링크**: https://www.data.go.kr/data/15100070/standard.do
- **데이터 기준일**: 2026-09-29 (원본 19,738행, CSV · CP949)

## 파일

| 파일 | 설명 |
|---|---|
| `selection.csv` | 선정 목록. `원본식품명,표시명,분류` (직접 관리) |
| `build_foods.py` | 원본 CSV + 선정 목록 → `foods.json` 생성 (파이썬 표준 라이브러리만 사용) |
| `foods_selected_raw.csv` | 선택된 원본 100행을 원본 컬럼 그대로 저장한 출처 증빙 |
| `app/src/main/assets/foods.json` | 앱이 읽는 결과물 |

## 다시 만들기

1. 위 링크에서 CSV를 내려받는다 (PC 브라우저, 인증키 불필요).
2. 프로젝트 루트에서 실행한다.
   ```bash
   python3 tools/food-data/build_foods.py ~/Downloads/전국통합식품영양성분정보_음식_표준데이터.csv
   ```
3. 원본에 없는 이름, 표시명 중복, 비어 있는 영양값이 있으면 파일을 만들지 않고 목록을 출력한다.

## 선정 기준

- **학생식당 메뉴 위주**: 밥 12 · 면·만두 10 · 국·탕 10 · 찌개 6 · 고기반찬 11 · 생선·해물반찬 5 · 달걀·두부반찬 6 · 기타반찬 8 · 채소반찬 15 · 김치·절임 5 · 간식·빵 7 · 음료 5
- **일반 음식만**: `업체명 = 해당없음` (프랜차이즈 제품 제외)
- **같은 이름이 여러 행일 때 출처 우선순위**: 실측 분석값을 먼저 고른다.
  1. 가정식(분석)
  2. 외식(분석)
  3. 산업체급식(산출)
  4. 중고등학교급식(산출)
  5. 초등학교급식(산출)
  6. 외식(산출)
  - 같은 순위끼리는 식품코드 순으로 고른다. 그래서 다시 실행해도 결과가 같다.
  - 결과: 분석값 80개, 급식·외식 산출값 20개

## 값 해석 규칙

- **영양값 기준**: `per100` 은 원본과 같이 100g(음료는 100ml) 기준이다. 섭취량 환산은 앱에서 `값 × 섭취량 / 100` 으로 한다.
- **단위(`unit`)**: 원본의 급식 산출 데이터는 고형 음식도 기준량을 `100ml` 로 표기한다. 그래서 단위는 분류로 정한다(음료만 `ml`, 나머지 `g`). 음료는 1ml ≈ 1g 으로 본다.
- **기본 섭취량(`servingSize`)**: 같은 이름의 산업체급식(성인 단체급식) 1인분 중량을 쓴다. 없으면 원본 식품중량을 쓰되, 분석 시료 단위인 100g 은 1인분이 아니므로 제외한다. 100개 중 87개에 값이 있고, 없는(`null`) 13개는 화면에서 기본값 100g 을 쓴다.
- **값 검증**: 모든 음식에서 `탄수화물×4 + 단백질×4 + 지방×9` 가 원본 열량과 15% 안에서 일치함을 확인했다.
- **`id`**: `selection.csv` 순서(1~100)다. 저장된 식사 기록이 이 값을 참조하므로, 데이터 확정 후에는 순서를 바꾸지 않는다. 추가할 때는 맨 끝에 붙인다.
